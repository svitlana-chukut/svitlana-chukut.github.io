ЯК ПЕРЕБИРАТИ ЗОБРАЖЕННЯ ВРУЧНУ
На самому сайті додано сторінку «Архів для аналізу» (меню «Більше» → «Архів для аналізу»):
там усі 462 зображення лежать за цими самими папками, з пошуком за назвою файлу,
фільтром за папкою та позначками «залишити / перевірити / кандидат на видалення».
Позначки живуть тільки до закриття вкладки; підсумок перебору вивантажується
кнопкою у файл .csv, який можна покласти поруч із цією папкою.
